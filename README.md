# flowza-midia

Hospedagem pública das mídias do Instagram @flowza.app.br.

A API de publicação do Instagram (Meta) baixa a mídia de uma URL HTTPS pública; este repositório existe só para isso.
As imagens são JPEG 1080x1350 (4:5) e os vídeos MP4 1080x1920 (9:16) — os mesmos arquivos que vão ao ar no perfil.

URL base (CDN): https://cdn.jsdelivr.net/gh/enzoocosta/flowza-midia@main/

Uma pasta por publicação, nomeada `AAAA-MM-DD_tema-curto`.
Fonte editável e pacotes de publicação ficam no projeto Flowza-Marketing, não aqui.
